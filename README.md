Aplicação desktop em Java para gerenciar contatos, com vinculacao em MySQL via JDBC.

O projeto implementa as operações básicas de **CRUD** (Create, Read, Update, Delete) e foi desenvolvido como atividade prática de faculdade.

Funcionalidades

- Cadastrar novos contatos (nome, telefone, e-mail e categoria)
- Listar todos os contatos em uma tabela
- Pesquisar contatos por nome em tempo real 
- Editar contatos existentes
- Excluir contatos, com confirmação
- Clicar em uma linha da tabela para carregar os dados nos campos do formulário
- Validação de campos obrigatórios (nome e telefone)
